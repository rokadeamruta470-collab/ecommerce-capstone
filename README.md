# Amruta Store - E-Commerce Capstone

A simple and modern e-commerce web application built using HTML, CSS and JavaScript.

## Project Overview

Amruta Store is a responsive e-commerce application that provides an interactive product catalog, shopping cart, simulated authentication and product management features.

The application uses the DummyJSON Products API for initial product data and LocalStorage for persistent cart, login and product state.

## Features

- Responsive e-commerce interface
- Product catalog
- Products loaded from API
- Product search
- Category filtering
- Price sorting
- Shopping cart
- Add products to cart
- Remove products from cart
- Cart total calculation
- LocalStorage persistence
- Login/authentication simulation
- Add new products
- Edit products
- Delete products
- Responsive mobile design
- Error handling for API loading

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- DummyJSON API
- LocalStorage
- Git and GitHub
- Vercel
